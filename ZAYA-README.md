# ZAYA — приложение для моделей и бизнеса

Версия 1.0.0. Читается на любой ОС: этот файл есть в форматах PDF, TXT и MD (одно и то же содержание).

## 1. Что это

Мобильное приложение (iPhone и Android) и веб-админка для агентства ZAYA (Ташкент).

- **Модель** регистрируется, заполняет анкету с фото, получает ежедневные задания для личного бренда (очки, ранги, значки, серия дней) и откликается на заказы.
- **Бизнесмен** создаёт заказ по брифу, видит подтвердивших моделей, выбирает нужных, смотрит 3D-каталог моделей и подсказки по PR и медиа.
- **Суперадмин** (веб-админка) проверяет анкеты и заказы, выбирает получателей, закрепляет выбор, отвечает на вопросы, управляет заданиями, контентом и пользователями.

Главное правило: **модели и бизнесмены не видят друг друга и не связываются напрямую**. Единственный посредник — менеджер ZAYA. Гонорар в бриф не входит, его согласует менеджер с моделью.

## 2. Как проходит заказ

1. Бизнесмен создаёт заказ (бриф) → статус «на проверке».
2. Менеджер проверяет, выбирает моделей-получателей → заказ «открыт», моделям приходит уведомление.
3. Модель видит заказ без данных заказчика и подтверждает или отказывается.
4. Бизнесмен видит подтвердивших (без контактов) и выбирает не больше моделей, чем указал в брифе.
5. Менеджер закрепляет выбор; выбранные модели получают уведомление «Вы утверждены».
6. Правка заказа после рассылки создаёт новую версию: менеджер проверяет её, затем моделям уходит уведомление, и они подтверждают заново.
7. Менеджер завершает заказ.

## 3. Что где лежит

| Папка | Назначение |
|---|---|
| `mobile/` | Приложение для iPhone и Android (Expo, React Native, TypeScript) |
| `admin/` | Веб-админка суперадмина (React, Vite) |
| `supabase/` | База данных (миграции SQL, тесты, стартовый контент) и функция отправки push |
| `scripts/` | Установщик для iPhone (`install-ios.mjs`), демо-данные, назначение суперадмина |
| `ZAYA-iOS-Install.*` | Запуск установщика двойным щелчком (Windows `.bat`, macOS `.command`, Linux `.sh`) |
| `docs/` | Подробные инструкции (`zaya-setup.md`, `zaya-release.md`), спецификация и планы |

Остальные файлы в корне репозитория относятся к стороннему учебному проекту и приложением ZAYA не используются.

## 4. Что установить

Работает на **Windows 10/11, macOS и Linux**.

| Нужно | Зачем | Где взять |
|---|---|---|
| Node.js 20 или новее | Запуск и тесты приложения и админки | nodejs.org (LTS) |
| Git | Получить код | git-scm.com |
| Аккаунт Supabase | База данных и вход пользователей | supabase.com (бесплатный тариф) |
| Аккаунт Expo | Облачная сборка приложения | expo.dev (бесплатно) |
| Apple Developer (99 $ в год) | Установка на iPhone через TestFlight | developer.apple.com |

Для сборки под iPhone **Mac не нужен**: приложение собирается в облаке Expo.

Windows: установщик запускается двойным щелчком по `ZAYA-iOS-Install.bat`; остальные команды выполняйте в PowerShell или Git Bash.

## 5. Проверка, что всё работает

    git clone <адрес репозитория>
    cd <папка репозитория>

Приложение:

    cd mobile
    npm ci --legacy-peer-deps
    npm test
    npx tsc --noEmit

Админка:

    cd admin
    npm ci
    npm test
    npm run build

Ожидаемый результат: все тесты зелёные (приложение 137, админка 33).

База данных (нужен Docker и Supabase CLI):

    supabase start
    supabase test db

## 6. Запуск для разработки

Приложение (нужен телефон с development-сборкой или эмулятор; Expo Go не подходит, потому что приложение использует вход через Apple/Google и push):

    cd mobile
    npx expo start

Админка:

    cd admin
    copy .env.example .env     (Windows)   |   cp .env.example .env     (macOS, Linux)
    npm run dev

В файле `.env` заполните `VITE_SUPABASE_URL` и `VITE_SUPABASE_ANON_KEY` (публичный ключ anon из панели Supabase). Ключ `service_role` нигде в приложении и админке не используется и в репозиторий не кладётся.

## 7. Выпуск приложения (без App Store и Google Play)

### База (один раз)
1. Создайте проект в Supabase.
2. В SQL editor выполните по очереди все файлы из `supabase/migrations/` (от `0001` до `0016`), затем из `supabase/seed/`.
3. Authentication → Providers: включите Email.

### iPhone (TestFlight): установщик

Самый простой способ — установщик, который сам спросит всё нужное и выполнит сборку в облаке:

- **Windows:** дважды щёлкните `ZAYA-iOS-Install.bat`.
- **macOS:** дважды щёлкните `ZAYA-iOS-Install.command` (в первый раз: правый клик → «Открыть»).
- **Linux, WSL, Git Bash:** `bash ZAYA-iOS-Install.sh`.

Он проверит Node.js, спросит Project URL и ключ **anon public** из Supabase (секретный ключ `service_role` не примет), установит зависимости, войдёт в Expo, соберёт приложение и отправит его в TestFlight. Пробный запуск без аккаунтов: `node scripts/install-ios.mjs --dry-run` (команды только показываются).

Если нужно вручную (например, в PowerShell):

    cd mobile
    npm ci --legacy-peer-deps
    npx eas-cli@latest login
    npx eas-cli@latest init
    npx eas-cli@latest env:create --name EXPO_PUBLIC_SUPABASE_URL --value https://<проект>.supabase.co --environment production --visibility plaintext
    npx eas-cli@latest env:create --name EXPO_PUBLIC_SUPABASE_ANON_KEY --value <anon-ключ> --environment production --visibility plaintext
    npx eas-cli@latest build -p ios --profile production
    npx eas-cli@latest submit -p ios --latest

Затем в App Store Connect → TestFlight добавьте тестировщиков и разошлите ссылку-приглашение. Сборка живёт 90 дней, потом выпускается новая. Первая сборка для внешних тестировщиков проходит короткую проверку Apple (обычно 1–2 дня).

### Android (APK)

    cd mobile
    npx eas-cli@latest build -p android --profile preview

EAS выдаст ссылку на `.apk`; отправьте её пользователям (на телефоне нужно разрешить установку из неизвестных источников).

### Первые данные
1. Зарегистрируйте в приложении тестовые аккаунты (две модели и бизнесмена).
2. Поправьте e-mail в `scripts/demo-data.sql` и выполните файл в SQL editor.
3. Суперадмин: зарегистрируйтесь ещё одним аккаунтом и выполните `scripts/promote-admin.sql` со своим e-mail.

Вход через Google/Apple и push-уведомления требуют отдельной настройки: `docs/zaya-release.md`, `docs/zaya-setup.md`.

## 8. Частые проблемы

| Симптом | Что делать |
|---|---|
| `npm install` ругается на peer dependencies | Для `mobile/` используйте `npm ci --legacy-peer-deps` |
| Приложение не открывается в Expo Go | Это нормально: нужна development-сборка или TestFlight/APK |
| После входа пустой экран или ошибка | Проверьте, что миграции применены полностью и в сборку переданы `EXPO_PUBLIC_SUPABASE_URL` и `EXPO_PUBLIC_SUPABASE_ANON_KEY` |
| Админка пишет «Нет доступа» | Аккаунту не назначена роль admin: выполните `scripts/promote-admin.sql` |
| Модель не видит заказы | Анкета не одобрена менеджером, или заказ не разослан этой модели |
| Нет push-уведомлений | Не настроены функция `send-push` и расписание (см. `docs/zaya-setup.md`), либо у телефона нет разрешения на уведомления |

## 9. Что важно знать

- Тесты базы данных в разработке запускались на временном PostgreSQL; перед боевым запуском один раз прогоните `supabase test db` в настоящем Supabase.
- Тексты заданий «Развития» и «Идей» на RU, UZ и EN — черновик, его должен утвердить ZAYA (узбекский и английский переводы нужно вычитать).
- Одобренная модель может менять контакты и фото без повторной проверки менеджером.
- Админка только на русском и без постраничной выдачи.
- Облачные сборки, вход через Google/Apple на телефонах и доставка push требуют ваших аккаунтов и в разработке не проверялись.

Подробные инструкции: `docs/zaya-setup.md` (запуск и настройка), `docs/zaya-release.md` (выпуск).
