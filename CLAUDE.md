# ZAYA — сайт zaya.uz

Статичный сайт: index.html (HTML/CSS/JS в одном файле) + zaya.png, monogram.png.

## Бренд
- Цвета: чёрный #050505, золото #DBB577, зелёный #0B2F23 (из логотипа).
- Шрифты: Cormorant Garamond (заголовки), Jost (подписи, текст).
- Слоган: «Твоя высота начинается здесь» / UZ: «Sening cho‘qqing shu yerdan boshlanadi» / EN: «Your heights begin here».
- Стиль: итальянский минимализм + тихая роскошь: много воздуха, тонкие линии, арки, тёплый «травертин» (секции `.paper`) против глубокого зелёного.
- Фон: живописный мрамор/масло — WebGL-шейдер в `<canvas id="bg">` (секция «painted background» в script). Без WebGL — CSS-градиент (`body.nogl`).
- 3D без библиотек (чистый CSS): логотипы «выдавлены» стопкой PNG по оси Z (`data-stack`), карточки-арки `.slab` с гранью/тенью и наклоном за курсором (`buildSlab`, `bindTilt`).
- Интро при входе: `#intro` (монограмма 3D → створки раздвигаются), раз за сессию; `?intro` в URL — показать снова; клик/Esc/Enter — пропустить.
- Реальные фото моделей: прописать URL в массив `PHOTOS` в script (3:4) — они встанут в 3D-арки вместо заглушек.

## Структура
- #home — лого ZAYA, слоган, две кнопки: «Клиентам» и «Моделям».
- #business — ZAYA Consulting: бизнес под ключ; 6 направлений (Маркетинг, IT, Юриспруденция, Отдел продаж, HR, R&D), этапы, для кого.
- #models — ZAYA Model Agency: условия вступления (18+), путь (заявка → кастинг → договор → портфолио), New Faces.
- Три языка RU/UZ/EN: строки в объектах T и C внутри <script>.

## Формы (бриф и анкета)
- Кнопки «Получить консультацию» / «Записаться на кастинг» / «Подать заявку» открывают модальное окно `#dlg` (`data-open="brief|apply"`), а не Telegram. Поля и тексты RU/UZ/EN — объект `FORMS` в script.
- Данные уходят POST'ом (JSON, `text/plain`) на Google Apps Script: URL в константе `FORM_URL` (пусто, пока не развёрнут). Код и инструкция: `apps-script/`.
- Анкета модели → лист `Info` таблицы ZAYA (колонки A:Y, «Отбор» = «Новая заявка»); бриф бизнеса → лист `Бизнес`. Значения в таблицу всегда пишутся по-русски.
- Модели младше 18: поле «Родитель» становится обязательным (в таблице уже есть «Детское направление»).
- Менеджер связывается сам; автоматических сообщений в Telegram нет.

## Музыка
- Кнопка-эквалайзер в шапке (`#snd`). Звук стартует с первого клика/нажатия клавиши (браузеры блокируют автозапуск), выбор «выкл» запоминается в localStorage (`zaya-music`).
- `MUSIC_SRC` в script: путь к своему треку (например `music.mp3`, должна быть лицензия). Пусто — играет встроенный сгенерированный ambient (WebAudio, без файлов).
