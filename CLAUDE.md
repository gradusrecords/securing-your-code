# ZAYA — сайт zaya.uz

Статичный сайт (все файлы сайта лежат в папке `site/`, она же корень публикации; в корне репозитория также `apps-script/` и этот файл): index.html (HTML/CSS/JS в одном файле) + catalog.html (3D-каталог) + bar.js (верхняя полоска: часы и курсы) + zaya.png, monogram.png, music.mp3.

## Бренд
- Цвета: чёрный #050505, золото #DBB577, зелёный #0B2F23 (из логотипа).
- Шрифты: Cormorant Garamond (заголовки), Jost (подписи, текст).
- Слоган: «Твоя высота начинается здесь» / UZ: «Sening cho‘qqing shu yerdan boshlanadi» / EN: «Your heights begin here».
- Стиль: итальянский минимализм + тихая роскошь: много воздуха, тонкие линии, арки, тёплый «травертин» (секции `.paper`) против глубокого зелёного.
- Фон: живописный мрамор/масло — WebGL-шейдер в `<canvas id="bg">` (секция «painted background» в script). Без WebGL — CSS-градиент (`body.nogl`).
- 3D без библиотек (чистый CSS): логотипы «выдавлены» стопкой PNG по оси Z (`data-stack`), карточки-арки `.slab` с гранью/тенью и наклоном за курсором (`buildSlab`, `bindTilt`).
- Интро при входе: `#intro` (монограмма 3D → створки раздвигаются), раз за сессию; `?intro` в URL — показать снова; клик/Esc/Enter — пропустить.
- Реальные фото моделей: прописать URL в массив `PHOTOS` в script (3:4) — они встанут в 3D-арки вместо заглушек.

## Атмосфера и две витрины (бывшие «времена года» убраны)
- Времена года, дождь, снег, погода и время суток удалены (по просьбе заказчика: «дождь создаёт депрессию»). Остался один спокойный фон — WebGL-мрамор (`<canvas id="bg">`), а его палитра зависит от витрины: `VPAL`/`VTINT`/`setMood(view)` в script (`body[data-view]`): главная — изумруд с золотом, «Бизнесу» — холодный сине-зелёный с серебристыми прожилками (и «холодная» бумага `.paper`), «Моделям» — тёплый чёрно-бронзовый.
- Две витрины: на главной выбор «Для бизнеса / Для моделей» сразу в первом экране; у каждой своё меню в шапке (группы `.ng-home/.ng-business/.ng-models`: Направления · Как работаем · Для кого; Кастинг · Лица · Каталог), своя палитра и свой героический экран. Якоря: `#directions #process #forwhom` (бизнес), `#conditions #faces-sec` (модели).
- Главная (`.qh-solo`) — строгая центральная композиция без фото: логотип, цитаты, кнопки «Для бизнеса / Для моделей». Героический экран `.qh` («Бизнесу», «Моделям»): слева крупная цитата, справа арка с фото (`.qh-arch`), у «Бизнесу» вместо фото — слова (Система · Рост · Команда · Результат); смена каждые 7,5 с, точки-таймер `.qh-dots`, пауза вне экрана. Данные — объект `DECKS` в script (цитаты RU/UZ/EN, фото `photos/…`); добавить слайд = добавить элемент в массив. Сейчас в слайдах только профессиональные фото Камиллы и Зиёвуддина (у остальных кастинговые кадры с номерком — для героя не годятся); нужны ещё хорошие студийные фото ≥1000 px по высоте. Цитаты написаны Claude в духе слогана и утверждены заказчиком.

- Живой кадр на главной: сейчас стоит ролик заказчика (исходник 640×360, 2 мин, неоновые фракталы), обработанный под серьёзный тон: тёмно-зелёная гамма, пониженная насыщенность, 40 с, бесшовная петля, 960×540, 1,4 МБ; в CSS увеличен ×1.45 от нижнего края, чтобы красный «глаз» не попадал в кадр. Если рядом с `index.html` лежит видеофайл `bg.mp4` (H.264, 1280×720, без звука, 10–20 с, до ~4 МБ, бесшовная петля), он плавно проявляется на фоне главной (`.bgv`, подгружается после интро; на других страницах и в фоновой вкладке ставится на паузу; не грузится при экономии трафика, медленной сети и «уменьшении движения»). Нет файла — остаётся тёмный мрамор. Для затемнения текста поверх видео: `body.has-video .qh-solo::before`.

## Верхняя полоска: часы и курс валют (`bar.js`)
- Тонкая фиксированная полоска над шапкой на всех страницах сайта и в каталоге (внутри iframe-панели каталога скрыта, там она уже есть у родителя). Слева — «Ташкент» и живые часы (Asia/Tashkent, с секундами), справа — курс UZS к USD, EUR, GBP со стрелкой ▲/▼ (изменение за день).
- Курсы: ЦБ Узбекистана (`cbu.uz/ru/arkhiv-kursov-valyut/json/`), запасной источник — open.er-api.com (без стрелок, если нет прошлого значения); последний удачный результат кэшируется в `zaya-fx`, обновление раз в 6 часов. Нет данных — «—».
- Язык подписей RU/UZ/EN берётся из `zaya-lang`. Цвета и шрифты из палитры (золото, кремовый, Cormorant Garamond/Jost). `bar.js` сам сдвигает `.nav` и `.ui.top` вниз на высоту полоски (`--fxh`, 30px). На узком экране остаются часы и три курса.

## Структура
- #home — путь посетителя сверху вниз: (1) лого ZAYA + слоган + «Узнать о нас»; (2) `#about` — кто мы и чем занимаемся (два направления); (3) `#choose` — развилка «Ты бизнесмен или модель?» с двумя арками «Клиентам» / «Моделям». Интро ведёт на (1).
- #business — ZAYA Consulting: бизнес под ключ; 6 направлений (Маркетинг, IT, Юриспруденция, Отдел продаж, HR, R&D), этапы, для кого.
- #models — ZAYA Model Agency: условия вступления (18+), путь (заявка → кастинг → договор → портфолио), New Faces.
- Три языка RU/UZ/EN: строки в объектах T и C внутри <script>.

## Формы (бриф и анкета)
- Кнопки «Получить консультацию» / «Записаться на кастинг» / «Подать заявку» открывают модальное окно `#dlg` (`data-open="brief|apply"`), а не Telegram. Поля и тексты RU/UZ/EN — объект `FORMS` в script.
- Данные уходят POST'ом (JSON, `text/plain`) на Google Apps Script: URL в константе `FORM_URL` (развёрнут, указан в index.html). Код и инструкция: `apps-script/`.
- Анкета модели → лист `Info` таблицы ZAYA (колонки A:Y, «Отбор» = «Новая заявка»); бриф бизнеса → лист `Бизнес`. Значения в таблицу всегда пишутся по-русски.
- Модели младше 18: поле «Родитель» становится обязательным (в таблице уже есть «Детское направление»).
- Менеджер связывается сам; автоматических сообщений в Telegram нет.

## Музыка
- Кнопка-эквалайзер в шапке (`#snd`). При первом визите, когда открылась шторка интро, внизу первой страницы появляется вопрос «Включить музыку? Да / Нет» (событие `zaya:ready`). Выбор запоминается в localStorage (`zaya-music`: 1/0); при следующих визитах вопрос не показывается, а если был «Да» — музыка стартует с первого клика (браузеры блокируют автозапуск). Кнопка-эквалайзер переключает в любой момент.
- Играет `music.mp3` — Maryam — Faqat sen (трек от заказчика, пережат до 128 kbps, ~2,7 МБ, 2:48; `?v=3` в пути — чтобы браузеры не держали старый трек в кэше, при следующей замене увеличить). Название задаётся константой `TRACK` в script. Путь — константа `MUSIC_SRC`; если её очистить, играет встроенный сгенерированный ambient (WebAudio), а плеер скрывается.
- Мини-плеер `#mp` (слева внизу, появляется после интро; по умолчанию свёрнут в золотой кружок `#mpmini`, раскрывается и сворачивается «джином» — анимации `gIn`/`gOut`, состояние в `zaya-mp`, кнопка «–» сворачивает): кнопка play/pause, «Сейчас играет» с эквалайзером, название «Maryam — Faqat sen», полоса перемотки и время; подписи RU/UZ/EN; прячется при открытой форме и панели каталога; название и кнопки управления дублируются в системном медиаплеере (`mediaSession`). Работает вместе с кнопкой-эквалайзером в шапке (общее состояние).

## Публикация на zaya.uz
- Домен куплен на Ahost (ahost.uz). План: Cloudflare Pages, репозиторий `gradusrecords/securing-your-code`, ветка для публикации — как решит заказчик, **корень публикации (Build output directory) = `site`**, команда сборки пустая. NS-серверы домена у Ahost меняются на выданные Cloudflare; custom domains: `zaya.uz` и `www.zaya.uz` (www → редирект на zaya.uz).
- В `site/`: `404.html`, `robots.txt`, `sitemap.xml`, `_headers` (кэш фото/музыки, базовые заголовки), иконки (`favicon-32.png`, `apple-touch-icon.png`), превью для ссылок `og.png` (1200×630), canonical и Open Graph в `index.html`.
- Почта info@zaya.uz (Zoho): MX/SPF/DKIM записи добавляются в DNS Cloudflare.
- После запуска проверить на реальном домене: формы (Apps Script), курс ЦБ (`cbu.uz`), музыка, каталог.
- Служебный код чужого проекта (Juice Shop) в корне репозитория на публикацию не попадает — публикуется только `site/`.
