# Фото моделей для каталога

Положите сюда фото с такими именами. `-1` — главное (на всю страницу), `-2` и `-3` — маленькие рамки справа. Достаточно одного главного фото; чего нет, то просто не показывается.

- формат JPG, вертикальные 3:4 (например 1200×1600), до ~300 КБ каждое;
- главное фото: лицо в верхней половине кадра (нижняя часть страницы затемняется под текст).
